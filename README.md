# Retail Company Analytics

An end-to-end Business Intelligence and Data Analytics project built to analyze retail company performance across sales, products, customers, returns, stores, and regions.

## Tools & Technologies

- SQL Server
- T-SQL
- SQL Views
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Project Overview

This project transforms retail data into actionable business insights through SQL Server data preparation, analytical SQL views, data modeling, and interactive Power BI dashboards.

The analysis focuses on:

- Sales performance
- Revenue trends
- Product and category performance
- Customer behavior
- Regional performance
- Store performance
- Returns analysis
