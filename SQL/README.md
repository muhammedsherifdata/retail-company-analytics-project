# SQL Analysis

This folder contains the SQL Server scripts used for data preparation, analytical views, and business analysis.

## SQL Workflow

1. Create database tables.
2. Load and prepare data.
3. Create analytical SQL views.
4. Perform business analysis.
5. Prepare datasets for Power BI.

## Analytical Views

The project includes analytical views for:

- Brand performance
- Regional sales performance
- Overall return rate
- Top VIP customers
- Top-performing products
- Top returned products
